# Пересборка метаданных детализации

`catalog-refinalize.mjs` исправляет только известную историческую оценку ошибки
грубого здания `32 → 2 m`. Контуры, высоты, transform, boundingVolume, ownership,
GLB, семантика, текстуры и исходный `compilerSourceHashes` сохраняются.
Допуск применим только к закреплённым SHA проверенной геометрической грамматики.
Новая грамматика требует отдельной проверки габаритов опущенных деталей.

```powershell
node tools/refinalize-city-visual-catalog.mjs --catalog .cache/city-visual-catalog-facades-v4/build-1a8f130975e5622d/catalog-4209606f9e6cb0e2.json --expected-sha 4209606f9e6cb0e22ea8c34d18fc57b184448429a36ab3084345c5b890b2ab50 --out .cache/city-visual-catalog-facades-v4-metric-lod
```

Команда работает только внутри `.cache`. Она проверяет каждый переиспользуемый
файл по размеру и SHA, создаёт hardlink в новом каталоге и никогда не меняет
содержимое существующего файла. Эти файлы нельзя редактировать на месте:
любое новое содержимое должно получать новый immutable путь.

После каждой ячейки сохраняется receipt. Повтор команды проверяет существующие
результаты; несовпадение или повреждение останавливает работу. Итоговый каталог
появляется только после всех ячеек. Подтверждённые пустые области наследуются
из закреплённого полного входного каталога. Повторная компиляция геометрии,
копирование 8 ГБ моделей, активация preview и обращение к облаку не выполняются.

Отдельный `metadataTransformation` содержит SHA исходного каталога, исходных
tileset/manifest каждой ячейки, SHA инструмента и проверенные границы деталей.
Это отдельная provenance операции с метаданными; она не подменяет историю
компиляции моделей. `pack.mjs` для будущих свежих сборок сразу записывает 2 m.

Проверки и фактические объёмы текущего прохода:
[`facade-full-catalog-20260909.json`](../../docs/evidence/facade-full-catalog-20260909.json).
Побайтовая целостность и полнота каталога не заменяют проверку изображения,
движения камеры и пользовательскую приёмку графики.
