# Пустой город на публичной странице — 2026-09-10

Камера пользователя: longitude 61.40544729905824, latitude 55.14238680897694, zoom 16.42008662505606, pitch 54.49329763506109, bearing -57.59246846758845; baseline, 2026, minute 1102.35719, tiled_game, fictional-city-v2.

Причина воспроизведена на Pages: данные загружались (872 строки акторов), но предел 256 узлов конфликтов включал консервативный запрет допуска всех новых акторов. В выходе worker было ровно 0 положительных opacity. HUD показывал количество исходных строк, которое не доказывает видимость.

Исправление увеличивает конечную ёмкость графа до 1024 узлов. Период промежуточного объединения остаётся 512 пересечений; лимиты путей, сегментов, парных проверок и подходов не меняются. Правила сигналов, приоритета занятых зон, пешеходных фаз и дистанций сохранены. При настоящем переполнении защитное поведение остаётся.

Регрессия сначала падала на 400 независимых перекрёстках. После изменения проверяет допуск разрешённого потока, остановку на красный на всех 400 узлах и сохранение безопасного отказа при явно уменьшенном лимите.

Проверки: `npm test` — 885 passed, 10 bulk-asset skips; Node publication/data suites — 189 passed, 7 bulk-asset skips; `npm run build` и `node tools/check-public-build.mjs` прошли (128 файлов). Дополнительная проверка уменьшенного лимита: 4/4 теста соответствующего файла.

Перед публикацией production JS/CSS подставлены браузерным тестом под публичным origin, данные и модели загружались с опубликованных адресов. На точной камере: 348 узлов, overflow 0, 357 положительных opacity, 244 движущихся акторов из 851 исходной строки. Screenshot просмотрен: машины видимы. Последний worker sample 36.4 ms, максимум 99.4 ms; это время worker, не FPS. Полная художественная/производительная приёмка города этим тестом не заявляется. Локальная копия данных в изолированной сборке неполна; прямой localhost smoke дополнительно ограничен CORS публичного хранилища.

Публичная проверка после деплоя выполняется отдельно. Научные данные, chat, billing и неизменяемые visual/movement manifests не изменяются.
