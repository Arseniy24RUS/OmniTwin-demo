## Локально проверенное исправление регрессии машин — 2026-09-09

В видимой пользователю локальной версии с новыми текстурами снова наблюдается
«телепортация» машин примерно каждые 6 секунд. Воспроизведена причина смены
отображаемого набора: каждые 5 секунд фильтр пересекающихся значков удалял
активные машины, затем те же canonical IDs возвращались дальше по маршруту. Камера:
61.40324326242887,55.166511972647186; zoom16.543982104833812,
pitch46.49661799282392, bearing-172.97699800600026; воспроизведение1×,
graphics=tiled_game, dataset=omnitwin-fictional-city-v2, время около12:30.
Статус: **overlap/membership regression verified locally**. Failing tests
воспроизвели замену уже видимой машины новым кандидатом и исчезновение одной
из двух ранее отображавшихся машин при их последующем пересечении.
DemoCity теперь сохраняет committed canonical-ID preference. Только tiled_game
сохраняет обе ещё активные машины при последующем пересечении; новые пересекающиеся
кандидаты ограничиваются, выбранный новый объект имеет приоритет. Перемотка и
смена смыслового контекста сбрасывают preference. Позиции, скорость и присутствие
по-прежнему определяет провайдер; отсутствующие машины из старого кадра не создаются.

В двух реальных 90-секундных Chromium-прогонах по 900 проб непрозрачные удаления
сократились **691 → 67**, повторные непрозрачные появления **527 → 31**.
Все 67 оставшихся удалений классифицированы по источнику и тем же точным границам:
63 машины выехали за viewport, 3 поездки завершились на работе и 1 дома.
Удалений активных машин внутри viewport — **0**, same-ID jumps по заданному
пороговому правилу — 0, page/HTTP errors и long tasks >50 ms — 0.
38 focused и 31 actor/bridge tests, typecheck и diff-check прошли. PNG открыты.

## Продолжение 2026-09-09: проверка загружаемых ресурсов

Renderer теперь получает точные byte/SHA-дескрипторы из проверенного manifest
и сверяет GLB/текстуры до передачи декодерам. Неполная или дублированная
inventory, изменённые байты, обрезанный/слишком большой поток и redirects
вызывают отказ. Ошибочные и отменённые потоки закрываются. Проверенный root
по-прежнему используется из памяти; повторной загрузки root нет. Проверяются
декодированные HTTP-байты, поэтому сжатый Content-Length не подменяет размер
исходного файла. Дополнительный постоянный кеш бинарных файлов не создаётся.

Шесть новых тестов воспроизвели прежний пропуск повреждений, после изменения
прошли. Полный frontend: **65 файлов / 485 tests PASS**, typecheck и production
build PASS. Audit build: 134 файла / 44 044 222 bytes, recognized embedded keys
не обнаружены; dependency check и `git diff --check` прошли.

Настоящий браузер загрузил appearance-пакет, выполнил приближение, вращение,
движение, паузу и mobile viewport. Четыре PNG `integrity-after` открыты:
геометрия и материалы видны, page/HTTP errors — 0. p95 — 15,4 мс,

## Что реализовано

- Three 0.185.1 внутри единственного MapLibre 6.4.1 canvas; `3d-tiles-renderer` 0.5.2 загружает GLB с meshopt. Самостоятельного Three RAF и старой диорамы нет.
- Квартал размером 1200 м вокруг `[61.39466,55.1654]`: 382 настоящих контура зданий, 808 исходных дорог, 1000 иллюстративных деревьев внутри разрешённых исходных зелёных полигонов. Пять GLB: общий coarse и четыре REPLACE-child. Родитель не исчезает до готовности замены.
- Фасады по реальным рёбрам, сохранённые отверстия дворов, окна/рамки, пояса/карнизы, крыши; восемь архитектурных семейств. Детали, не известные из источника, имеют `visual_synthesis`.
- Настоящие объёмные CC0-модели Quaternius/Kenney. Позы запечены в общие GPU-данные, экземпляры используют метрический масштаб и GPU-интерполяцию. Огонёк уступает телу при 8–14 CSS px. Лимиты ближних экземпляров и облегчённые представления работают отдельно от численности населения.
- Дорожные потоки общего плана берутся из всего реального viewport. Они непикируемые и не имеют профилей. Их отдельный предел low/mid/high — 256/768/1024 штриха, один retained draw.
- Подготовка движения сохраняет последнюю работоспособную версию до готовности следующей и включает потенциальных входящих персонажей. 16× больше не отменяет загрузку бесконечно.
- Добавлена ограниченная проверка синтетических sidewalk-смещений по настоящим контурам. Неисправный самокасающийся контур `openmaptiles_buildings:185832733` в соседней ячейке блокируется своим консервативным прямоугольником, а не отключает весь индекс; геометрия источника не изменяется. В реальном quarter-тесте guard содержит 500 полигонов / 4401 вершину / 72 432 bytes typed buffers. **Это ещё не исправление всех пешеходных маршрутов:** в первой этой проверке 146 смещений были заблокированы, применено 0, непроверенных смещений 0. Полные source-коридоры выходят за проверяемую область или имеют неподдержанные повороты. Их нельзя объявлять корректными тротуарами.
- Выбор людей/машин/зданий связан с существующими карточками. Raycast сравнивает текущую геометрию тела с геометрией здания; это click-only CPU raycast квартального прототипа, не заявленный GPU-picking.
- Native-здания скрываются только при готовом полном покрытии viewport игровым пакетом. Вне квартала и при неисправности сохраняется базовая карта. Увеличение/вращение не выключает материалы.

## Проверки и доказательства

Сохраняются PNG viewport и fullpage, JSON состояния/сети/ошибок, отдельные measurement windows и WebM. Промежуточные кадры со старой надписью загрузки были отклонены при ручном просмотре, несмотря на проходящий DOM-тест.

Финальный frontend/renderer прогон: **59 файлов / 421 тест прошли**, 28,42 с, один worker. Также прошли 44 compiler tests, public-shell exclusion test, `tsc --noEmit`, production Vite build и `git diff --check`. Три отдельные реальные Playwright-проверки прошли: квартал/поворот/движение/reload, мобильная компоновка и общий план→wheel→16×. Финальный квартальный повтор — 25,8 с. Кадр reload с ещё загружающимся населением был отдельно сохранён как отклонённый: проверка теперь ждёт и жителей, и готовности моделей, а не только зданий. Все 20 итоговых PNG и контактный лист открыты и просмотрены. Мобильные скриншоты показывают компоновку и расположение badge, без утверждения о быстродействии телефона. Машиночитаемый итог: `docs/evidence/tiled-game-checkpoint-20260908.json`.

Проверенные реальными кликами карточки:

- `demo2-p-0897965`: профиль Дмитрия Кузнецова, 41 год, «Пешком»;
- `demo2-v-0800036`: автомобиль с одним пассажиром из четырёх мест; переход к `demo2-p-0800036`, профиль Павла Крылова, «В автомобиле»;
- `openmaptiles_buildings:1139362990`: 230 находящихся внутри, 269 назначенных работников; следующая страница показывает 51–100 из 230, итог не становится размером первой страницы.

Это проверки конкретных экземпляров нового **вымышленного** набора, не наблюдение реальных людей и не доказательство правильности всех зданий города.

Финальное независимое 5-секундное окно движения после двух секунд прогрева: 580 зарегистрированных MapLibre render events, средняя частота 115,8 FPS, median 120,5 FPS, p95 16,0 мс, p99 16,7 мс; непрерывных участков с интервалом свыше 33,4 мс в этом окне нет. После стабилизации паузы — 0 кадров за 2,1 с. Классификация всех замеров — `contaminated_diagnostic`: национальная модель не останавливалась, фон не контролировался. Это не чистый release benchmark и не экстраполяция на телефон.

Настройка scheduler `60` ограничивает только его запросы; MapLibre также реагирует на события. Причина наблюдённых ~120 render events/s при такой настройке отдельно не доказана. Не объявлять её работающим жёстким 60-FPS limiter. Мобильный Chromium viewport доказывает только компоновку, не производительность настоящего телефона.

## Визуальный вердикт и незакрытые пункты

На открытых PNG видны объёмные автомобили, ближние люди, окна, крыши, деревья и тени. Нет исчезновения всех материалов при правом вращении. Но **SimCity-like художественная приёмка не пройдена**: большие дворы остаются пустыми, фасады/крыши повторяются, графический общий план вне квартала всё ещё нативный. Увеличение счётчика объектов не закрывает эти недостатки.

Перед расширением и публикацией остаются:

1. Уличное и дворовое окружение, разнообразие архитектуры; законченные переходы общих потоков/огоньков/тел по всем камерам и выбранному ID.
2. Полноценные метрические albedo/normal/roughness/AO, 2048/1024 KTX2 с padding/mipmaps и проверенным fallback. Сейчас только сгенерированный albedo PNG и геометрические нормали/материальные roughness; это не полный PBR-пакет.
3. Дорожные высоты, мосты, тоннели, crossing/lane-lite и проверенные многосегментные маршруты. В квартальном compiler неподтверждённые разноуровневые участки исключены; универсальная высота акторов остаётся 0,13 м.
4. Полный визуальный pipeline семи районов, снижение 55-МБ квартального бюджета, жёсткий общий GPU/cache budget, реальное устройство low/mobile. Сейчас mid geometry cache 192 MiB плюс плановый резерв 64 MiB, не абсолютная граница памяти драйвера.
5. Проверенный GLB/texture integrity при streaming, slow/failing tile cases, день/вечер/погода, native pan и все необходимые interaction/occlusion тесты.
6. Совместимый публичный V2 backend/chat, проверенные Storage/CORS-ресурсы и атомарное переключение demo. Прежняя публичная версия сохранена для отката, ключ и лимиты OpenRouter не трогались.

Скиллы frontend-testing-debugging/react-best-practices повлияли на обязательный реальный браузерный screenshot gate и отсутствие React-состояния для каждого кадра акторов. Imagegen использован только для исходного общего художественного albedo, а не для подмены результатов рендера.
