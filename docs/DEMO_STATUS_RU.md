# OmniTwin Demo — состояние реализации, 7 сентября 2026

Собрано отдельное статическое демонстрационное приложение. Научное ядро, национальные файлы населения и работающий модельный процесс не изменялись.

## Реализовано

- РУДН, авторская ссылка, пять разделов, городской экран со сводкой и адаптивными карточками.
- Исходный синтетический набор 8 225 → 8 246 сохранён. Новый публичный набор начинается с 8 246 вымышленных жителей; три согласованных сценария показывают интерфейс, а не научный прогноз.
- Пирамида, компоненты изменения, таблицы, CSV, фильтры и численное сравнение сценариев. Контекст группы, года, территории, сценариев и поиска сохраняется в URL; визуальные часы независимы.
- Один MapLibre canvas, interleaved люди и автомобили, source-backed улицы/здания, фасады, крыши, водная фактура и растительность в допустимых исходных областях. Клик открывает профиль, пассажиров или список здания.
- Небольшой статический пакет центра: 42 реальных MVT-тайла и проверенный начальный layout. Вне его покрытия используется потоковый картографический источник. Это не обещание полностью офлайн-доступного Челябинска.
- Остановка анимации при паузе/уходе в аналитику, сохранение камеры, экскурсия, мобильные панели и общие иллюстрированные портреты взрослых персонажей.
- Подготовлен защищённый сервер чата с проверяемыми профилями, подписанными сессиями и устойчивыми квотами. При отсутствии сервиса работают явно обозначенные локальные реплики.
- GitHub Actions, статическая сборка с deployment base, Yandex deployment templates, полный комплект атрибуции и лицензий.

## Проверено

1. Чистая установка вне рабочего окружения: `npm ci`, `data:build`, проверка единственности deck/luma, TypeScript, production build и 110 публичных файлов.
2. 82 frontend/unit-теста; 20 серверных тестов. Живой YDB и платный LLM-вызов в эти проверки не входят.
3. Реальный headed Chromium, один worker: 7 из 7 production Playwright-тестов прошли за 53,8 с. Подмен API, canvas и ответов тайлов нет.
4. Desktop 1920×1080, portrait 390×844, landscape 844×390; настоящие canvas-клики по человеку, машине и зданию; движение, pan/wheel, 2D/3D, Back/reload, сценарии, поиск, пагинация и чат-fallback.
5. Группа женщин 18–34: 707 жителей одинаково в аналитике и городской сводке. События, не определённые для группы, остаются `null`.
6. В паузе после стабилизации — **0 дополнительных кадров за 2 секунды**, позиции неизменны. Короткий интервал движения показал median frame 8,3 мс / p95 9,2 мс, но имеет статус `contaminated_diagnostic`, а не performance release gate.
7. В итоговом прогоне нет console/page errors и HTTP errors. Остаётся предупреждение deck об уже нормализованном атрибуте цвета; оно не скрывалось.
8. Реальные PNG открыты визуально. Исправлены пропадавшие начальные экструзии, тёмные фасады, неотображённые footways, линия через воду, потерянное последнее обновление паузы и несовместимые версии luma в чистой сборке.

Полные PNG и сетевые/телеметрические журналы остаются в локальном QA-архиве оператора. Концепты не являются доказательством работы продукта. Внешний вид остаётся стилизованным; фотореалистичность концепта не заявляется.

## Ещё не выполнено

- Публичный Pages endpoint должен быть включён владельцем репозитория и проверен после реального GitHub Actions deployment. Наличие workflow само по себе не означает публикацию.
- Yandex Cloud, YDB, Gateway, Object Storage и отдельный OpenRouter-ключ с лимитом $5 ещё не активированы этой реализацией. Секреты вводятся только в облачной конфигурации, не в Git или чат. Живой ИИ не считается подключённым до end-to-end вызова.
- Нужны проверки доступности публичного сайта из целевых сетей и чистые performance-замеры на других устройствах. Универсальные 30 FPS не объявляются по одному диагностическому измерению.
- Научная валидация модели остаётся отдельной незавершённой задачей. Эта демонстрация её не заменяет.

## Техническая воспроизводимость

Зафиксированы deck.gl 9.3.10 и согласованная группа luma.gl 9.3.6. Регрессионный gate запрещает несовместимые версии и дубликаты глобального core. Public-ресурсы сохраняются Git без преобразования строк: SHA-256 должен совпадать на Windows и Linux. Сервер чата не получает произвольный профиль из браузера и не сохраняет разговоры.
