# OmniTwin Demo

Демонстрация исследовательской платформы: потоковая карта Челябинска, вымышленные жители, связанная аналитика и подготовленные иллюстративные сценарии. Научная модель и локальный Presentation API для просмотра не нужны.

## Запуск

Нужны Node.js 24 и npm. Из корня репозитория:

```sh
npm ci
npm run data:build
npm run dev
```

Адрес сообщает сервер; по умолчанию `http://127.0.0.1:5178/OmniTwin-demo/`. При занятом порте Vite выбирает следующий, не завершает чужие процессы. Production: `npm run build`; результат `apps/web/dist`.

## Что можно попробовать

1. Откройте живой город, перемещайте карту, меняйте часы и погоду.
2. Перейдите в «Аналитика»: возраст/пол, численность, компоненты изменения, таблица и CSV.
3. В «Сценарии» сравните две подготовленные траектории. Черновик предположений не запускает научный расчёт.
4. Выберите группу на пирамиде, откройте жителя, найдите его на карте. Нажмите здание или автомобиль для просмотра присутствующих.
5. Задайте жителю вопрос. До подключения защищённого сервиса ответы явно помечены как локальные демореплики.

## Данные и ограничения

- Исходные синтетические агрегаты `synthetic-chelyabinsk-v1`: 8225 на2025-01-01 и8246 на2026-01-01. Это НЕ население реального Челябинска.
- Новый публичный набор содержит8246 вымышленных жителей на2026-01-01 и три детерминированных сценарных ledger на2026–2036. Это иллюстрации интерфейса, не оценённая научная модель, наблюдения или прогноз.
- Годы демографического среза независимы от времени визуализации. Размещение, маршруты и автомобили синтетические; геометрия улиц/зданий получена из картографических источников.
- Ограниченный набор видимых акторов не равен населению; большинство жителей не рендерится вне зданий.
- Научная валидация ещё не завершена. Реальные научные микроданные не публикуются.

## Публикация

Workflow `.github/workflows/pages.yml` собирает Node-only приложение, проверяет данные и публикует `apps/web/dist`. В настройках GitHub Pages нужно выбрать GitHub Actions. Все frontend-пути поддерживают `/OmniTwin-demo/`; `DEMO_BASE=/` позволяет собрать корневое размещение.

Крупные источники можно вынести в Yandex Object Storage; настройка чата и облачные ограничения описаны в `deploy/yandex/`. `apps/web/public/runtime-config.json` содержит только публичный адрес API — никаких ключей. Не включайте зарезервированные экземпляры и автоматическое пополнение.

GitHub Pages и внешняя картографическая служба требуют сетевой доступности. Наличие workflow не означает, что сайт уже опубликован. Работа облачного ИИ подтверждается только отдельной проверкой развёрнутого сервиса.

## Проверки

```sh
npm test
npm run build
node tools/check-public-build.mjs
npm run test:e2e
```

Playwright запускает один headed Chromium worker и настоящую страницу без подмены tile/API responses. Скриншоты сохраняются вне репозитория. Снимки должны быть открыты человеком/визуальным инструментом; прохождение DOM-теста не является визуальной приёмкой. FPS под параллельной модельной нагрузкой — только `contaminated_diagnostic`.
